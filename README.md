# DoppleJa V1

Two sides. Two Yes. One Match.

A swipe-based job matching platform connecting local workers
and employers in Germany.

## Stack
- Python / FastAPI
- PostgreSQL / PostGIS
- Redis
- SQLAlchemy / Alembic
- HTML / CSS / JavaScript
- Docker Compose
- GitHub Actions
- Nginx / VPS

## Matching
No CVs. No traditional applications.
Mutual likes unlock direct chat.
